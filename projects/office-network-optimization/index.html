多樓層辦公網路
核心與存取層優化

針對使用者連接 NAS、印表機及網際網路時頻繁斷線的問題，盤點原有家用 Hub 多層串接架構，重新規劃 Aruba 1930 核心交換器與六台 Zyxel GS1200-8 存取交換器，並將迴路防護與非授權 DHCP 防護納入核心設定。

專案類型企業網路優化
主要設備Aruba / Zyxel
核心技術STP / BPDU Guard / DHCP Snooping
專案階段現況盤點、架構與設定規劃
01

BACKGROUND

專案背景與使用者回饋

實際使用問題

辦公室使用者透過電腦或 Wi-Fi 存取 NAS 與網路印表機時，斷線頻率高；大量檔案傳輸或列印期間容易中斷，使用網際網路時也經常出現無法連線的狀況。

改善優先順序

本案先以網路穩定度為第一目標，重新整理交換與上行架構。網速與 Wi-Fi 體驗屬於後續優化項目，避免在基礎網路尚未穩定前同時更動過多因素。

問題 01NAS 與印表機連線頻繁中斷
問題 02辦公室上網連線不穩定
問題 03多台家用 Hub 串接且缺乏防護
02

ROOT CAUSE

原有架構為什麼不穩定

ISSUE 01

家用 Hub 多層串接

  • 設備缺乏完整的流量與迴路管理能力。
  • 多人同時傳輸時容易產生瓶頸與延遲。
  • 線路若形成 Loop，可能引發廣播風暴並影響全網。
  • 多層串接後難以定位是哪一個節點造成異常。
ISSUE 02

無線設備同時負責有線分流

  • 部分 AP／無線分享器被當成 Hub 使用。
  • 有線轉發與無線服務集中在同一設備，增加負載。
  • NAS 與印表機需要長時間穩定的有線連線，不適合依賴這種串接方式。
  • 設備私接也可能帶入迴路或第二個 DHCP Server。

核心層：在防火牆與內部網路之間加入 Aruba 1930，集中處理內網資料轉發、上行與管理。

存取層：六個樓層節點改用 Zyxel GS1200-8，取代原有家用 Hub 串接。

終端層：AP 專注提供無線服務；NAS、印表機與電腦由交換器提供穩定的有線連線。

04

EQUIPMENT

設備配置與選擇

CORE / 01

Aruba Instant On 1930

新增一台核心交換器，提供 Gigabit 連線、SFP+ 擴充空間與集中式網頁／行動管理，並承擔 STP Root、上行與內網轉發角色。

ACCESS / 06

Zyxel GS1200-8

六台網管型存取交換器分布於各樓層前後區域，支援 VLAN、QoS 與基礎流量管理，取代原本不易管理的家用 Hub。

WIRELESS

AP 回歸無線服務

不再將 AP 當作主要有線分流設備，降低設備負載，也讓有線與無線問題可以分開管理及排查。

EXPANSION

保留維護與光纖擴充

核心交換器保留 MIS 臨時維護埠，SFP+ 埠則供未來樓層距離超過銅纜限制或伺服器需要 10G 連線時使用。

05

CORE CONFIGURATION

核心交換器設定規劃

設定項目用途本案規劃
VLAN 與 Port Mapping

建立可追蹤的樓層上行與管理方式。

VLAN 1 作為設備管理；防火牆使用核心上行，各樓層前後區域分配獨立實體埠，並保留擴充埠。

STP Root Priority

決定生成樹根節點並防止二層迴路。

將核心交換器 Priority 設為 4096，使拓樸以核心為 Root Bridge 收斂。

BPDU Guard / PortFast

防止未授權交換器接入後形成迴路。

未使用與終端型埠啟用基礎防護；若收到 BPDU，介面進入保護狀態。

DHCP Snooping

避免私接設備對內網錯誤派發 IP。

僅信任防火牆上行來源，其餘存取埠維持非信任狀態。

06

DESIGN DECISIONS

這次規劃的判斷重點

STABILITY FIRST

先處理穩定，再追求速度

  • 先移除不易管理的家用 Hub 串接。
  • 讓交換器承擔有線資料轉發。
  • 確立核心與樓層節點後，再觀察 Wi-Fi 與頻寬需求。
MANAGEABILITY

讓每條上行都可以被辨識

  • 建立樓層與實體埠對照。
  • 保留維護及未來擴充介面。
  • 透過 STP、BPDU Guard 與 DHCP Snooping 降低人為接線風險。
07

EXPECTED OUTCOME

預期改善與交付成果

01

提升內外網穩定度

以分層交換架構取代家用 Hub 多層串接，降低封包壅塞與單一節點異常擴散。

02

改善 NAS 與列印連線

將 NAS、印表機與電腦接回網管交換器，減少大型傳輸或列印工作中途斷線的風險。

03

降低迴路與錯誤 DHCP 風險

以 STP、BPDU Guard 與 DHCP Snooping 建立二層網路的基本防護。

04

留下可維護的設定文件

完成網路架構圖、核心 Port Mapping、STP、BPDU Guard、DHCP Snooping 與設定項目說明。

這個專案不是單純把設備換新，而是把原本無法管理的串接方式，整理成有核心、有樓層分工，也能追蹤與防護的辦公網路。
